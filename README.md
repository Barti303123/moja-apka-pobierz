# Moja Apka — do pobrania

Zadania, nawyki, cele, notatki, budżet i skupienie w jednej apce.
Logujesz się swoim kontem Google. Twoje dane widzisz tylko Ty.

## Android

1. Na telefonie otwórz: **[Pobierz Moja Apka (Android)](https://github.com/Barti303123/moja-apka-pobierz/releases/latest/download/MojaApka.apk)**
2. Otwórz pobrany plik `MojaApka.apk`.
3. Telefon zapyta, czy pozwolić przeglądarce instalować aplikacje. Wybierz
   **Ustawienia → Zezwól**, wróć i stuknij **Zainstaluj**. To pytanie pojawia
   się tylko raz.
4. Jeśli Google Play Protect pokaże ostrzeżenie: **Więcej szczegółów →
   Zainstaluj mimo to**. Apki po prostu nie ma w Sklepie Play.

## Windows

1. Pobierz: **[Moja Apka — instalator (Windows)](https://github.com/Barti303123/moja-apka-pobierz/releases/latest/download/MojaApka-instalator.exe)**
2. Uruchom `MojaApka-instalator.exe`.
3. Windows pokaże niebieskie okno „System Windows ochronił ten komputer”.
   Kliknij **Więcej informacji → Uruchom mimo to**. Instalator nie jest
   podpisany (podpis jest płatny), więc to normalne.
4. Kliknij **Dalej / Zainstaluj**. Apka pojawi się w menu Start.

## Aktualizacje

Gdy wyjdzie nowa wersja, apka sama pokaże u góry pasek **„Jest nowa wersja”**.
Stuknij **Pobierz** i zainstaluj plik tak samo jak za pierwszym razem.
Twoje dane zostają, bo są na Twoim koncie.
